HAT — установочный комплект
===========================

Windows
-------
1. Распакуйте архив в отдельную папку.
2. Дважды щёлкните «Установить HAT.cmd».
3. После установки дважды щёлкните «Запустить HAT.cmd».

Linux / macOS
-------------
1. Распакуйте архив.
2. Откройте терминал в распакованной папке.
3. Выполните: ./install.sh
4. Затем: ./start.sh

Инсталлятор создаёт изолированное окружение внутри распакованной папки. При первом
запуске требуется интернет: библиотеки загружаются автоматически. В Windows установщик
также сам установит Python 3.12 для текущего пользователя, если Python отсутствует.
В Linux/macOS требуется системный Python 3.12 или новее.

После запуска интерфейс автоматически откроется по адресу http://127.0.0.1:8765/.
Для остановки нажмите Ctrl+C в окне запуска.

Реальные журналы выбираются через интерфейс и хранятся локально в runs/. Они не входят
в установочный архив. Не переносите содержимое runs/ в публичные репозитории.
