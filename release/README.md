# Скачать HAT

ZIP не хранится в Git как бинарный файл. Он автоматически создаётся после каждого
изменения основной ветки:

1. Откройте вкладку **Actions** репозитория.
2. Выберите последний успешный запуск **Build HAT installer**.
3. В разделе **Artifacts** скачайте `HAT-Installer-1.0.1`.

После скачивания распакуйте ZIP и запустите `Установить HAT.cmd`, затем
`Запустить HAT.cmd`.

Внутри artifact находятся ZIP и его контрольная сумма SHA256.
